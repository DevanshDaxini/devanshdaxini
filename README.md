I'm a CS freshman at **UC San Diego** who gets unreasonably interested in problems at the intersection of AI and the real world — medical triage without internet, sports models that beat sportsbook lines, image pipelines that catch counterfeit listings.

Most of my projects start from a question I couldn't answer with existing tools. Then I build until it works.

---

## 🔨 What I've Built

**[MeDAKit](https://github.com/devanshdaxini)** — Offline AI medical triage assistant for disaster zones. Runs fully on-device via Ollama + Gemma, returns analysis in under 1.5s, handles 100 simultaneous hotspot connections. Built at a hackathon. Zero internet required.

**Sports Betting Predictive Engine** — XGBoost + scikit-learn pipeline forecasting NBA player stat lines with 75% accuracy. Pulls live matchup data, runs daily predictions, serializes models for game-day inference.

**IP Protection & Copycat Detection** — ORB + SSIM image comparison pipeline that autonomously scrapes and flags counterfeit listings. Custom scoring algorithm to minimize false positives.
